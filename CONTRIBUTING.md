# Contributing

1. Fork the repository.
2. Create a feature branch.
3. Keep crawler changes respectful of destination-site access controls.
4. Run `python -m compileall app` and `pytest -q` before submitting a PR.
5. Do not add CAPTCHA bypass, credential bypass, paywall bypass, or anti-bot evasion features.
